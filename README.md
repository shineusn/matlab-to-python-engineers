# From MATLAB to Python for Engineers and Scientists

**Companion code repository** for the book:
*"From MATLAB to Python for Engineers and Scientists: Hands-On Comparison Guide (2026 Edition)"*

> All examples are tested and runnable. Every chapter includes both `.m` (MATLAB) and `.py` (Python) files side by side.

## Quick Start

```bash
# Option 1: pip
pip install -r requirements.txt

# Option 2: conda
conda env create -f environment.yml
conda activate matlab-to-python
```

## Repository Structure

```
chapter_02_syntax/          # Core syntax comparison
chapter_03_numerical/       # NumPy & SciPy vs MATLAB matrices
chapter_04_data_analysis/   # pandas vs MATLAB tables
chapter_05_visualization/   # matplotlib vs MATLAB plots
chapter_06_image_processing/ # OpenCV vs Image Processing Toolbox
chapter_07_signal_processing/ # SciPy.signal vs Signal Toolbox
chapter_08_workflows/       # Modern engineering workflows
appendix/                   # MATLAB ↔ Python quick reference table
notebooks/                  # Jupyter notebook versions
```
